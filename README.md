# Biblioteca de Prompts — Artigas Abogados

Biblioteca de prompts del despacho: organización por categorías, edición del nombre
de los elementos, reordenación del menú y copia rápida. Página **estática**
(`index.html`), optimizada para **GitHub Pages**.

## Demo (GitHub Pages)
1. Sube `index.html` a un nuevo repositorio.
2. Activa **Settings → Pages → Deploy from a branch → main / (root)**.
3. La biblioteca quedará accesible públicamente.

## Uso local
Abre `index.html` en tu navegador (doble clic). No requiere servidor ni dependencias.
